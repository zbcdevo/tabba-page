# tabba-page

Public landing page and privacy policy for **tabba**, a guitar & bass tab editor
by Zabba Labs. The app's source lives in a private repository, so this repo hosts
everything that needs to stay public:

- **[Landing page](https://zbcdevo.github.io/tabba-page/)**: what the app is,
  its features, and how to get in touch.
- **[Privacy Policy](https://zbcdevo.github.io/tabba-page/privacy.html)**:
  linked from the Google Play Store listing.
- **Issues**: bug reports, feature requests, and general feedback for the app
  are welcome here via the [issue templates](.github/ISSUE_TEMPLATE).

Served with GitHub Pages from `main` (root).
